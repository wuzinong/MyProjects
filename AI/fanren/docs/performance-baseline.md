# 性能基准档案

## 基准环境

- 设备：开发机（Windows，Node.js v24，V8 单线程）
- 模拟频率：60 Hz 固定步长；模拟步预算 ≤ 8 ms（渲染另计 ~8 ms）
- 压力场景：`tests/sim/stress.test.ts` — 500 活跃敌人 + 全技能满级（含大庚剑阵持续伤害与连锁雷电）

## 结果（2026-08-10）

| 指标 | 目标 | 实测 |
| --- | --- | --- |
| 模拟步耗（500 敌） | < 8 ms | < 1 ms（600 步均值） |
| 空间网格查询（1500 实体） | < 1 ms/查询 | 通过 |
| 5 批 ×300 步内存增长 | < 50% | 通过（无单调增长） |

## 渲染侧预算

- 精灵按视锥剔除 + 池化复用；画质档位限制同屏精灵数（低 700 / 中 1200 / 高 1800）。
- DPR 上限 2；低画质渲染分辨率 0.75×。
- 复测方法：`npx vitest run tests/sim/stress.test.ts`。
